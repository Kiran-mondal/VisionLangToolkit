api API Documentation

Endpoint Details

Send a multipart/form-data POST request containing an image to extract its resolution, file size, and primary color palette.

POST /analyze
curl -X POST "https://visionlangtoolkit-production.up.railway.app/analyze" \ -H "Content-Type: multipart/form-data" \ -F "image=@/path/to/your/image.jpg"

JSON Response

{ "filename": "sample.jpg", "width": 1920, "height": 1080, "file_size": "1.2 MB", "resolution_category": "Full HD (1080p)", "colors": ["#FFFFFF", "#000000"] }
